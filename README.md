# Nikhil Sable Portfolio V2

A modern and responsive developer portfolio built with Next.js, React.js, Tailwind CSS, and Framer Motion to showcase my projects, skills, and experience.

## Live Demo
https://nikhilsable.vercel.app/

## Tech Stack

- Next.js
- React.js
- Tailwind CSS
- Framer Motion
- Google Apps Script
- Vercel

## Features

- Responsive design
- Smooth scroll animations
- Projects showcase
- Experience timeline
- Resume download
- Contact form with email integration

## Run Locally

```bash
npm install
npm run dev
